# 🚗 Overview

This project focuses on designing a 3D automotive alloy wheel model using CATIA.  
The objective of the project is to explore CAD modeling, automotive component design, surface modeling, and wheel aesthetics used in modern vehicles.

The design demonstrates engineering creativity, automotive styling concepts, and 3D CAD development skills.

# 🚘 Design Workflow

Sketch ➜ Pad ➜ Pocket ➜ Circular Pattern ➜ Surface Finishing ➜ Final Wheel Model

---

# 🚀 Steps to Create the Model

1. Create base sketch of wheel
2. Use Pad feature for thickness
3. Design spoke structure
4. Apply circular pattern
5. Create center hub
6. Add finishing features
7. Apply material/render appearance
8. Generate final 3D model
